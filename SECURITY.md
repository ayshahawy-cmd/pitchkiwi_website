# Security policy

Report website vulnerabilities through [GitHub Private Vulnerability Reporting](https://github.com/ayshahawy-cmd/pitchkiwi_website/security/advisories/new). Describe the affected route, commit/version, impact, and a minimal synthetic reproduction. Do not open a public issue for undisclosed vulnerabilities or attach real addresses, credentials, recordings, or transcripts.

Security fixes target the default branch and current deployment on a best-effort basis. Older website snapshots have no promised backports or response time. If private reporting is unavailable, request a private channel through [the maintainer profile](https://github.com/ayshahawy-cmd) without disclosing details.

The native app has its own [security policy](https://github.com/ayshahawy-cmd/pitchkiwi/blob/main/SECURITY.md).
