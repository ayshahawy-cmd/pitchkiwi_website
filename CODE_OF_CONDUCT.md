# Code of conduct

Be respectful, practical, and welcoming. Critique ideas and code rather than people. Harassment, discrimination, threats, sexualized attention, deliberate intimidation, disruption, and publication of private information are unacceptable.

This applies to issues, pull requests, reviews, and project spaces. Maintainers may warn, remove content, close contributions, or restrict participation, considering the impact and preserving reporter privacy where possible.

For private conduct concerns, contact [Ahmed Yasser (@AhmedYsrrr)](https://x.com/AhmedYsrrr). If private messages are unavailable, request a private channel without posting sensitive incident details. There is no independent moderation team or guaranteed response time. Security reports follow [SECURITY.md](SECURITY.md).
