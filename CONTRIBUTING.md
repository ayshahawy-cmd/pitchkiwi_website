# Contributing

Use Node.js 22+ (24 is pinned in `.nvmrc`), clone the repository, run `npm ci`, then `npm run dev`. See [README.md](README.md) for environment setup, routes, and deployment.

Create a branch in your fork, keep the change focused, and open a pull request to `main`. Explain the user-visible result and run `npm run lint`, `npm test`, and `npm run build`. Update documentation when routes, installation, licensing, or data handling change. Add behavioral tests when changing a serverless handler.

Preserve direct public downloads, accurate beta/signing status, accessible controls, and the distinction between local app processing and external website hosting. Never commit credentials, real user email lists, private transcripts, recordings, personal screenshots, `.env`, or hosting tokens. Use synthetic examples and original assets.

Contributions are distributed under the [MIT License](LICENSE); submit only work you have the right to license. Follow the [code of conduct](CODE_OF_CONDUCT.md). Report vulnerabilities privately using [SECURITY.md](SECURITY.md).
